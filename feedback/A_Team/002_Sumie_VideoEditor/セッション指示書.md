### STEP 1: プロンプト実行（Claude Code）
以下のプロンプトを Claude Code に **そのまま貼り付け** して実行

```
あなたは売れるLPを作るデザイナー兼コピーライターです。
特に「女性をターゲットにしたLP」のデザイン・コピーが得意で、AIっぽい定型句を一切使わずに作ります。
以下の「LP構成案」をもとに、HTMLとCSSでランディングページを作ってください。
構成案の順序・文面はそのまま使ってください。

【コピーのルール】
- 主語は「あなた」、抽象語禁止（「自信がつく」「あなたの可能性を広げる」「理想の○○へ」など中身のない言葉は一切使わない）
- AI定型句禁止（「さあ、始めましょう」「いかがでしょうか？」「〜の世界へようこそ」「革新的な」など）
- 数字・固有名詞・動詞から始まる文を意識する
- 架空のお客様の声や数字（「満足度97%」等）は作らない。プレースホルダーで置く
- 女性ターゲットに感情を動かす言葉を使う（プリンセスマーケティング視点）
- 機能的価値＋情緒的価値の両方を **1つのリスト・1つの文章** に混ぜ込む（2セクションに分けない）
- 「できるようになること / 感じられるようになること」「🔧 / 💛」のような分類見出しを使わず、各項目内で「○○できる ── ○○な気持ちが手に入る」のように1行内に併記
- キャッチコピーは「ターゲット × 悩み × ベネフィット」を内包
- 見出しは短く（10文字前後。長い説明文を見出しにしない）／各項目の本文は「要点1文＋補足1文」まで（だらだら書かない）
- 太字の要点はキャッチコピー調かつ具体的に（何が起きるか分かる）。◎ 具体的な成果や数字が見える短い言葉／×「理想の私へ」「新しい一歩」のような詩的すぎる表現はNG

【デザインのルール】
- 絵文字一切禁止（チェック等はCSS疑似要素で）
- フォント最大3種類。明朝体を長文本文に使わない
- 色：アクセント1色のみ。原色そのまま禁止、派手なグラデ禁止
- テキスト#1e1e1e / 補足#6a6a6a / 背景#faf8f5（純白でなく少し色味のある白）
- 角丸は6〜8pxで統一
- シャドウは薄く広く（0 8px 30px rgba(0,0,0,0.05)）
- 女性ターゲット向けの柔らかさ・上質感

【フォントサイズ（clamp必須）】
- 本文16px以上、H1 clamp(28px,7vw,48px)、H2 clamp(22px,5vw,32px)、H3 clamp(17px,4vw,22px)
- 本文行間1.7〜1.8 / 見出し行間1.3〜1.4

【レスポンシブ対応（PC・スマホ両方で崩れない）】
- ブレークポイント768px
- 横スクロール禁止、タップ領域44px以上
- 2カラム以上はスマホで縦積みに切り替え

【余白・レイアウト】
- セクション間：PC 80px / スマホ 48px
- 要素間は8の倍数（8/16/24/32px）
- 左右パディング最低20px、テキストmax-width: 720px

【ビジュアル】
- 全セクションに画像 or 図解必須。なければpicsum.photosやCSS図解
- 絵文字をアイコン代わりにしない（SVG or CSS疑似要素）
- 画像はwidth: 100%; max-width: 100%

【セクションごとの推奨カラム（モデリングLPの世界観優先・迷ったときのデフォルト）】
- FV: PC2col（左テキスト60%+右画像40%）/ スマホ縦積み
- 共感: PC3colカード / スマホ1col
- 未来: PC2col(Before/After) / スマホ縦積み
- サービス: PC2col×3行 / スマホ1col
- 信頼: PC3colカード / スマホ1col
- プロフィール: PC2col(左画像40%+右テキスト60%) / スマホ縦積み
- FAQ: 全幅1col（アコーディオン推奨）
- 料金: 中央寄せ1col (max-width: 480px)
- CTA: PC中央寄せ・ボタン幅固定 / スマホボタンフルワイド

【出力フォーマット】
- HTML 1枚完結、CSSはstyle内、altテキスト必須

サービス内容

サービスの特徴・選ばれる理由
・【機能面】動画編集チームのトップが直伝：
  巷の小手先テクニックではなく、数多くの動画を見てきたプロの目線で、有料版CapCutの「本当に使うべき機能」だけを絞って教えるので迷いません。

  質問しづらいギスギスした雰囲気は一切なし。できない気持ちが分かる講師と、お互いを褒め合う大人の女性だけの特別な空間だから、安心して楽しめます。

・第2週： その他大勢から抜け出す！垢抜けフォント・エフェクトを使い倒す「世界観プロデュース」
・第3週： 1本に何時間もかけない！プロの作業効率を再現するサクサク編集テンプレート構築
・第4週： ファンを引き寄せる！自分のビジネスの想いを100%届けるリール動画完成・発信強化WEEK

・Q1：本当に機械音痴で、パソコンの画面を見るだけでフリーズしてしまうのですが、大丈夫ですか？
  - A：大丈夫です！みなさん最初は動画編集を難しく考えすぎてしまいますが、本講座では難しい専門用語を一切使わず、直感的にわかる言葉で一歩ずつ一緒に進めます。一人でフリーズさせない温かい環境ですので、安心して飛び込んできてくださいね。
・Q2：PC版のCapCutは、無料ではなく有料プラン（Pro）にしないといけませんか？
  - A：はい、本コミュニティでは有料プランを使い倒すことをおすすめしています。無料版ではできることが全体の10分の1ほどしかなく、周りと差別化ができません。有料版だからこそ使えるプロ仕様の機能を味方につけて、その他大勢から一瞬で抜け出す体験を一緒にしましょう！
・Q3：50代〜60代なのですが、周りの若い人たちに混ざるのが少し気恥ずかしいのですが……。
  - A：ご安心ください！私の講座には、あなたと同じように「これから自分を変えたい」と挑戦されている年配の方がたくさん受講されていますので、どうぞ安心してくださいね。自分のビジネスや発信を大切に育てたい「大人の女性」のための特別な空間です。「私なんか…」という言葉は卒業して、お互いを応援し合いながら温かく進んでいきましょう。
・Q4：スマホやタブレットで参加できますか？
  - A：本講座は「PC版CapCut」を使いこなして圧倒的な格差をつけるための特訓コミュニティとなっております。そのため、スマホやタブレットではなく、必ずパソコンをご用意の上ご参加ください。
・Q5：講義の時間にリアルタイムで参加できない時はどうすればいいですか？
  - A：もちろんアーカイブ配信をいたします！お仕事や家事でお忙しい方でも、ご自身の好きなタイミングで何度も見返して復習していただけますのでご安心ください。
・Q6：1ヶ月間、仕事や家事で忙しくても、途中で挫折せずに続けられるでしょうか？
  - A：はい、一人で孤独に作業するのではなく、プロの講師や仲間と毎日繋がれる環境を用意しています。分からないことはその場で解消でき、みんなで一緒に完走を目指す仕組みなので、忙しい日常の中でもモチベーションを保ったまま走りきれますよ。
・Q7：分割払いはできますか？
  - A：決済システム上、一度一括でお支払いいただいた後、ご自身がご利用されたクレジットカード会社にて各自で分割払いの手続き（あとから分割・リボ払い等）をお願いしております。
```
