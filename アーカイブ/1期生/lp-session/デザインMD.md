# LP デザインルール

以下のルールをすべて守って、ランディングページをHTMLで作成してください。

■ コピー（文章）のルール
━━━━━━━━━━━━━━━━━━━━━━

【禁止するコピー表現】
「あなたの可能性を広げる」「新しい一歩を」「理想の〇〇へ」
「本当の自分を取り戻す」「すべてが変わる体験」
のような、中身のない抽象的なコピーは一切使わないこと。

【禁止するAI定型句】
「さあ、始めましょう」「いかがでしょうか？」「〜の世界へようこそ」
「革新的な〜」「今こそ〜のとき」は使わないこと。

【代わりにやること】
・数字を入れる（「90分で完成」「参加者80名」「週3時間の節約」など）
・固有名詞を入れる（ツール名・サービス名・地名・具体的なテーマ）
・動詞から始める（「作る」「設定する」「確認する」など）
・情報が足りない箇所は勝手に作らず「ここに〇〇を入れてください」とプレースホルダーにする

【絶対禁止】
架空のお客様の声・人物名・実績数字（「満足度97%」など）は作らないこと。
実績セクションが必要な場合は「ここにお客様の声を入れます」とダミーで置くこと。

■ デザインのルール
━━━━━━━━━━━━━━━━━━━━━━

【絵文字】
✨ 🔥 💡 🎯 💪 🚀 ⭐ 📌 🎉 👑 💫 などの絵文字は一切使わないこと。
チェックマークやリスト装飾はCSSの疑似要素（::before）や左ボーダーで実装すること。

【フォント】
・書体は最大3種類まで。4種類以上は使わないこと。
・明朝体を長い本文に使わないこと。

【フォントサイズ】
・本文：16px以上（14px以下は禁止）
・大見出し（H1）：font-size: clamp(28px, 7vw, 48px)
・中見出し（H2）：font-size: clamp(22px, 5vw, 32px)
・小見出し（H3）：font-size: clamp(17px, 4vw, 22px)
・セクションラベル：11px
・注釈・補足：12px
・PCとスマホで同じサイズのままにしないこと（clampを使うこと）

【色】
・アクセントカラーは1色だけ使う。3色以上は禁止。
・色はCSS変数（:root）で管理すること。
・テキスト：#1e1e1e
・補足テキスト：#6a6a6a
・背景は純白（#ffffff）ではなく、#faf8f5 など少し色味のある白にする。
・原色（red, blue, greenなど）をそのまま使わないこと。
・派手なグラデーションは禁止。使う場合は同系色の微細な変化のみ。

【レイアウト・余白】
・セクション間の余白：PC 80px / スマホ 48px
・要素間の余白は8の倍数で統一（8, 16, 24, 32px）
・左右パディングは最低20px確保すること（スマホで端が切れないように）
・テキストに横幅の制限を入れること（max-width: 720px 推奨）
・シャドウは薄く広く：box-shadow: 0 8px 30px rgba(0,0,0,0.05)
・角丸は8pxか16pxに統一すること。要素ごとにバラバラにしない。

【行間】
・本文の行間：1.7〜1.8
・見出しの行間：1.3〜1.4

■ スマホ対応（レスポンシブ）のルール ← 追加
━━━━━━━━━━━━━━━━━━━━━━

【基本方針】
・モバイルファーストで設計すること（スマホ基準でCSSを書き、PC向けにmedia queryで上書き）
・ブレークポイントは768pxを基準にする

【スマホで禁止すること】
・横スクロールが発生するレイアウト
・タップできないほど小さいボタン（最低44px × 44px）
・2カラム以上の横並びをそのままスマホに持ち込む
  → スマホでは必ず縦積みに切り替えること

【具体的な対応】
・PCで2カラムのセクションは @media (max-width: 768px) { flex-direction: column; } で縦積みにする
・PCで3カラムのカードは @media (max-width: 768px) { grid-template-columns: 1fr; } で1列にする
・ナビゲーションはスマホでハンバーガーメニューにするか、非表示にする
・フォントは clamp() を使い、スマホで自動的に小さくなるようにする

■ ビジュアル要素のルール ← 追加
━━━━━━━━━━━━━━━━━━━━━━

【写真・画像】
・すべてのセクションに写真または図解を必ず入れること
・写真がない場合は以下のいずれかを使うこと：
  - プレースホルダー画像（picsum.photos などの適切なサービス）
  - CSSで作ったシンプルな図解（グラデーション・アイコン代わりのSVG）
  - 「ここに〇〇の写真を入れてください」とコメントを入れる
・人物写真のある箇所は object-fit: cover で正方形または横長にトリミングする
・画像は必ず width: 100%; max-width: 100%; を設定してスマホで崩れないようにする

【図解・アイコン】
・テキストだけのセクションを作らないこと
・アイコンはSVGで実装するか、CSSの形（::before/::after）で代替する
・絵文字をアイコン代わりに使うことは禁止

【セクションごとのカラム指定】

FV（ファーストビュー）
・PC：左右2カラム（左テキスト60% ＋ 右画像40%）
・スマホ：画像を上、テキストを下に縦積み

お悩みセクション
・PC：3カラムのカードグリッド
・スマホ：1カラム縦積み

ビフォーアフター
・PC：左右2カラム（左Before ＋ 右After）
・スマホ：縦積み（Before → After）

サービス内容
・PC：2カラム（左アイコン＋タイトル ＋ 右説明文）を3行
・スマホ：1カラム縦積み

選ばれる理由
・PC：3カラムのカードグリッド
・スマホ：1カラム縦積み

プロフィール
・PC：左画像40% ＋ 右テキスト60%
・スマホ：画像を上、テキストを下

FAQ
・PC：1カラム（全幅・アコーディオンまたは全展開）
・スマホ：同じ（元から1カラムなので変更不要）

料金
・PC：中央寄せ1カラム（max-width: 480px）
・スマホ：同じ

CTA
・PC：中央寄せ、ボタンは幅固定（max-width: 360px）
・スマホ：ボタンをフルワイド（width: 100%）
